## Task Taken: Task (c) — New Deploy Script

The 2026-06-16 dev log listed DataAuditLog as the only contract without a deploy script.
This session adds `scripts/deploy-data-audit-log.ts`.

**`scripts/deploy-data-audit-log.ts`** — Deploy + demo script for DataAuditLog

### Modeled after
`scripts/deploy-data-subject-rights.ts` — same SDK plumbing, same Bug 5/6 fixes, same
WalletFacade.init API, same 6-step main() flow.

### What it does
1. **Deploy**: Deploys `DataAuditLog` to preprod/preview/standalone
2. **Join**: Joins existing deployment at a known address (`--join <address>`)
3. **Demo**: Runs full LGPD Art. 37 audit event lifecycle with 6 events across 3 circuits
4. **Saves**: Writes `deployment-data-audit-log-<network>.json` with address + tx info

### Demo scenario
- Controller "BancoXYZ S.A." (identified only by `sha256(name+CNPJ)`) — no PII on-chain
- Actor hashes for analyst and DPO officer — no PII on-chain

Demo steps:
1. `logEvent(type=1, data_collection)` — new customer onboarded (Art. 37)
2. `logEvent(type=2, data_access)` — internal analyst query (Art. 37)
3. `logEvent(type=4, data_transfer_third_party)` — shared with credit bureau (Art. 7 VIII)
4. `getControllerEventCount` → 3, `getLastEventType` → 4, `getLastEventBlock` check
5. `logDeletionRequest(controller, actor, block)` — customer exercises Art. 18 VI
6. `confirmDeletion(controller, actor, block+100)` — erasure confirmed within 15-day window
7. `logBreachEvent(controller, block)` — security incident notified to ANPD (Art. 48)
8. Query all aggregate counters: `getTotalEvents`=6, `getTotalDeletionRequests`=1,
   `getTotalDeletionsConfirmed`=1, `getTotalBreachEvents`=1, `getControllerEventCount`=6

### Block number note
DataAuditLog uses `block_number: Uint<16>` (max 65535, ≈45 days at 1 block/min).
The demo clamps to `& 0xFFFF` to avoid overflow. The contract comment explains the limitation
and suggests modular block chunks for longer-lived deployments.
