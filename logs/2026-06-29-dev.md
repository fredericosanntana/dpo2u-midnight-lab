## Work Done This Session

### New script: `scripts/deploy-all.ts`

**Problem**: The 3 individual deploy scripts each initialize and sync a wallet independently.
On preprod, wallet sync can take 10–30 minutes per contract — 3 sequential deploys = 30–90 min
of avoidable overhead. There was no way to deploy all 3 contracts with a single wallet sync.

**Solution**: Added `scripts/deploy-all.ts` — a unified deploy orchestrator that:
1. Derives HD keys once from a shared seed
2. Syncs the wallet **once**
3. Deploys ConsentRegistry → DataAuditLog → DataSubjectRights in sequence, reusing the synced wallet
4. Saves all 3 deployment JSON files (consumed by `interact-full-suite.ts`)
5. Prints a unified summary with all 3 contract addresses and the interact command

**Key design decisions**:
- Shared `WalletFacade` instance across all 3 deploys (no re-sync, no key re-derivation)
- Each contract gets its own `levelPrivateStateProvider` (separate private state store names: `cr-private-state`, `dal-private-state`, `dsr-private-state`) and `NodeZkConfigProvider` pointing to its own build dir — required for correct ZK asset loading
- `--skip-cr / --skip-dal / --skip-dsr` flags allow partial re-deploy without touching already-deployed contracts
- Standalone default: uses genesis seed `000...001` (has prefunded tNIGHT) — zero-config first run
- Preprod/preview: requires explicit `--seed` flag (prevents accidental seed generation loss)
- All 7 SDK workarounds applied: `setNetworkId()` first (Bug 4), `finalizeRecipe` not `signRecipe` (Bug 5), `walletProvider` in `levelPrivateStateProvider` (Bug 6), smoldot override assumed in package.json (Bug 7)

**Output files**:
- `deployment-consent-registry-<network>.json`
- `deployment-data-audit-log-<network>.json`
- `deployment-data-subject-rights-<network>.json`

These are exactly what `interact-full-suite.ts` reads via `--from-json`.

**Usage**:
```bash
# Standalone (genesis seed, no docker sync wait):
npx tsx scripts/deploy-all.ts --network standalone

# Preprod (requires your seed):
npx tsx scripts/deploy-all.ts --network preprod --seed <64-hex> --faucet

# Skip already-deployed contracts:
npx tsx scripts/deploy-all.ts --network preprod --seed <64-hex> --skip-cr

# Then run the full LGPD lifecycle:
npx tsx scripts/interact-full-suite.ts --network standalone --seed <64-hex>
```
