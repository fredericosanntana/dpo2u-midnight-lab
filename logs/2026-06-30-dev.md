## Scripts added / modified

### 1. `scripts/status.ts` (new)

A standalone read-only status reporter that fills the gap between `deploy-all.ts` and `interact-full-suite.ts`. It:

1. Reads deployment JSON files for all 3 contracts
2. If any contract is missing, reports which ones and suggests deploy-all.ts
3. If all deployed, syncs the wallet, joins all 3 contracts, and queries **global on-chain counters** only:
   - ConsentRegistry: `total_consents_granted`, `total_revocations`
   - DataAuditLog: `total_events`, `total_deletion_reqs`, `total_breach_events`
   - DataSubjectRights: `total_requests`, `total_fulfilled`, `total_rejected`, `total_overdue`
4. Prints deployment addresses + live counters in a single summary

This is useful for checking contract health at any point after deploy — without needing to run the full 5-phase lifecycle demo.

**SDK patterns used** (consistent with deploy-all.ts and interact-full-suite.ts):
- `WalletFacade.init()` — 2.0.0 API
- `finalizeRecipe` — Bug 5 workaround (no `signRecipe()`)
- `walletProvider: bridge` in `levelPrivateStateProvider` — Bug 6 fix
- `setNetworkId()` called before any contract operation
