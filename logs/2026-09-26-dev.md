## O que mudou
- `scripts/lib/wallet-facade.ts` (novo): `startWalletFacade()` constrói os três
  sub-wallets, `new WalletFacade(...)` e `await wallet.start(...)` — API 1.0.0.
  O `UnshieldedWallet` 1.0.0 exige `txHistoryStorage`; usa
  `InMemoryTransactionHistoryStorage`.
- Os 6 scripts: bloco `WalletFacade.init({...})` → `startWalletFacade(...)`.
  Cabeçalhos/comentários que diziam "2.0.0 (WalletFacade.init API)" corrigidos;
  o JSON de deployment gravava `'wallet-sdk-facade': '2.0.0'` (metadado falso
  no artefato) → `'1.0.0'`.
- `package.json`: novo `npm run typecheck` (`tsc --noEmit -p tsconfig.json`),
  para que esse tipo de desvio quebre na hora e não em produção.
